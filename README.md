a soft little collection of tools, aesthetics, and affirmations for femboys, enbies, and everyone who likes things cute.

## 🎀 What's inside

| File | What it does |
|------|--------------|
| `src/cuteness-enhancer.py` | adds maximum softness to any string |
| `aesthetics.json` | pastel color palettes, emoji sets, and vibes |
| `affirmations.txt` | daily reminders that you are valid and cute |

## 💅 Installation

```bash
git clone https://github.com/mnk-works/femboy-toolkit.git
cd femboy-toolkit
pip install -r requirements.txt  # there are none, we keep it soft
```

## ✨ Usage

```python
from cuteness_enhancer import enhance
```
